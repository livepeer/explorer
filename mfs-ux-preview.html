Delegation under Min-Fee-Stake

Issue #802 ↗

Livepeer 2.0 changes how inflationary LPT is earned: reward % = min(fee % of network, stake % of network). USDC fees for work stay uncapped. Stake only unlocks more LPT when a node is earning more fees than it has stake behind it.

Goal: help prospective delegators see where new stake still earns, and help anyone already bonded see whether their node is full or still has room, without teaching the formula first.

Visual system: blue = fees, violet = stake. State color follows whichever side is smaller. We avoid green/amber so neither state reads as success or failure. Numbers are shares of the network, not APY.

Design decisions

  • Shares of the network, not APY. Emissions are still unsettled in the litepaper. The UI shows how stake moves a node’s reward ceiling (for example from 2.3% toward 11.8%), not a dollar or percent-per-year forecast.
  • Seven settled rounds on the list. Default windows match the proposed reward delay. Single-round spikes are easy to game; per-round history is a separate reward-history design.
  • State chips replace “Active.” “Active” today means membership in a capped set. That cap goes away, so we show Room to earn / Full / Balanced instead of overloading the old word.
  • 21-day move lockup is shown as the working assumption. If protocol keeps instant bond transfers, that note is removed before ship. Copy is written so it can flip with the parameter.
  • Validator scoring is not in this design. Honesty scores and validator set UX are a separate ticket so this review stays focused on fee-vs-stake delegation.
