Explorer design review

One review for 802, 803, and 804. Mockups for those issues. Each one uses the Explorer sidebar and content panel, on the route where that work would ship. Numbered markers open the matching note under each surface.

Using these mockups

  • Numbered markers on each surface link to notes. Issue tabs sit below the surface.
  • The Delegator and Node operator switch above a profile is for review only. It shows both views on one page and has a dashed outline and a “Review only” label. The product has no such switch.
  • Deep links such as #n-orch-3 can be pasted into GitHub issue comments.
  • “Hide markers” gives a clean view for screenshots.
  • Review at narrow and wide widths. Some surfaces only exist on mobile, like the amount drawer and the History drill-in.
  • On a Vercel preview, start at /design/mocks. Locally, run npm run dev or pnpm dev and open the same path. Relative asset paths also work when opening the HTML from disk.

Livepeer aesthetic

  • Charcoal layers, Inter, Geist Mono for figures, a sidebar and a content panel. Dark is the default; the Appearance button in the sidebar switches to light.
  • Buttons (36px, outline by default, one primary per panel), badges, tables and stat tiles match the Explorer components. Green is an accent and never fills a button.
  • No em dashes. No protocol parameter names in the visible UI.

Color meaning

  • Fees Blue (#3987e5) means fees and USDC.
  • Stake Green (#40bf86) means stake and LPT. Green is not a good/bad signal.
  • State chips use an icon and a label, tinted by the side that limits rewards. LPT and USDC are written as text, with no logo marks. Cap status icons are the same across 802 and 803.
  • Issue markers use violet / magenta / orange accents so fee blue and stake green stay free. Each marker’s accessible name includes the issue number.

Who can use this

Shared rules for every issue. Issue tabs on each mockup point here so the same text is not copied onto every page.

  • Chips. Each chip has an icon and a label. Fee and stake shares are also written as numbers. LPT and USDC are written out.
  • Keyboard. Filters, modes, and lists are real choice groups (arrow keys, Home / End). Focus is a soft green ring. Dialogs and drawers trap focus; Escape returns you to the control that opened them.
  • Screen readers. Choosing a filter, mode, round, or validator is announced as a real choice. Opening an amount drawer, claim dialog, or score sheet is modal: focus stays inside, Escape or Close returns you to the control that opened it.
  • Help without a mouse. Dotted-underline terms open their tip on hover and when you tab to them. You can move onto the tip. Escape dismisses that tip until the next hover or focus.
  • Motion. If the system asks for reduced motion, smooth-scroll is off and pressed buttons stay put.
  • Skip ahead. “Skip to content” jumps past the intro into the first surface on each mockup.

Cross-issue ownership

  • 802 covers fee-versus-stake for the current round. Surfaces: the Orchestrators list, an orchestrator’s page, and Portfolio.
  • 803 covers past rounds. Surface: reward receipts on a delegator profile and on a node operator profile, with entry lines from the node page and Portfolio.
  • 804 covers honesty. Surfaces: the Validators page and the honesty section on an orchestrator’s page. A past receipt may show the honesty factor that applied; the live score board stays on the node page and on Validators.
