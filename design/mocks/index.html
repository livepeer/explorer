Explorer design review

One review for 802, 803, and 804. Pages are organized by Explorer screen (one mockup per place). Numbered markers open the matching note under each surface.

How to view the mocks

  • Numbered markers on each surface link to notes. Issue tabs sit below the surface.
  • Deep links such as #n-orch-3 can be pasted into GitHub issue comments.
  • “Hide markers” gives a clean view for screenshots.
  • Review at narrow and wide widths. Some surfaces only exist on mobile, like the amount drawer and the History drill-in.
  • On a Vercel preview, start at /design/mocks. Locally, run npm run dev or pnpm dev and open the same path. Relative asset paths also work when opening the HTML from disk.

Livepeer aesthetic

  • Inter only. Flat surfaces. Dark green theme (dark-theme-green).
  • Buttons, focus, lists, and dialogs match @livepeer/design-system sizing from the Explorer.
  • No em dashes. No protocol parameter names in the visible UI.

Color meaning

  • Fees Brand blue (#25abd0) means fees.
  • Stake Brand green (#4cc38a) means stake or LPT quantity.
  • Chips use an icon, a label, and a 1.5px border. LPT and USDC marks share one canon. Cap status icons are shared across 802 and 803.
  • Issue markers use violet / magenta / orange accents so fee blue and stake green stay free. Each marker’s accessible name includes the issue number.

Who can use this

Rules every issue repeated, written once. Issue tabs on each mockup link here instead of repeating them.

  • Chips carry more than color. Icon, label, and a 1.5px border. Fee and stake shares are also written as numbers. LPT and USDC marks are named. Selected list rows use a wash plus a 1px green ring.
  • Keyboard. Filters, modes, and lists are real choice groups (arrow keys, Home / End). Focus is a green ring. Dialogs and drawers trap focus; Escape returns you to the control that opened them.
  • Screen readers. Choosing a filter, mode, round, or validator is announced as a real choice. Opening an amount drawer, claim dialog, or score sheet is modal: focus stays inside, Escape or Close returns you to the control that opened it. LPT and USDC marks are named.
  • Help without a mouse. The “?” tips open on hover and when you tab to them. You can move onto the tip. Escape dismisses that tip until the next hover or focus. The painted mark is 16px; the hit area around it is larger.
  • Motion. If the system asks for reduced motion, smooth-scroll is off and pressed buttons stay put.
  • Skip ahead. “Skip to content” jumps past the intro into the first surface on each mockup.
