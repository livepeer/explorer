1. Table follows the Explorer list #802

The columns are the ones the Explorer list already has: estimated return, reward calls, reward cut, 30d fees, total stake. Return, reliability and fee trend come first. The fee-versus-stake state is one quieter column on the right.

↑ Show in mock

Design decisions on this mockup

  • Return first. The first three columns are what a node may pay, whether it shows up every round, and whether its fees are growing.
  • “Limited by.” One column for whether stake or fees cap the node’s rewards. It sits after the compare columns.
  • Seven settled rounds. The window is the last week of settled work, which is harder to game than a single round and lines up with when rewards are paid.
  • LPT and USDC are written out. No logo marks. The text is enough and reads faster in a table.

Open questions on this mockup

  • Fee trend source. The trend needs 180 days of fees per node. Confirm the subgraph can give it before this column ships. The numbers here are samples.
  • Tables on phones. The table stays a table on narrow screens. It scrolls sideways and the node name stays pinned, so the return columns are easy to compare.
  • “All active” filter. Under today’s rules it means nodes in the capped set. Livepeer 2.0 drops that set, so the filter needs a new definition before it ships.

Accessibility and color rules: review hub.
